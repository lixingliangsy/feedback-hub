### What is user feedback clustering?
- slug: `what-is-feedback-clustering`
- type: Definitional · FAQPage
- query: what is user feedback clustering
- body: Clustering groups similar notes into themes (bugs, pricing, UX) so you prioritize by frequency and severity instead of the loudest message.

- slug: `how-to-turn-feedback-into-a-roadmap`
- type: How-to · HowTo
- query: how to turn user feedback into roadmap
